# 项目测试说明

本目录中的 `test.py` 用于验证校园二手交易平台部署后的主要功能是否能够正常工作。测试范围包括前端页面、后端接口、数据库查询、商品图片和用户登录鉴权。

脚本只会发送查询请求和登录请求，不会新增、修改或删除商品、用户、订单等业务数据。脚本完全使用 Python 标准库，无须安装第三方依赖。

## 运行条件

运行测试前，请确认：

1. 前端、后端和数据库均已启动。
2. 测试设备可以访问待测试的网站。
3. 已安装 Python 3.9 或更高版本。
4. 数据库中存在可供查询的商品记录。
5. 已准备一个能够正常登录的测试账号。
6. 指定的商品图片已经上传并且可以通过网站访问。

## 测试内容

脚本依次执行以下检查：

1. 前端首页是否能够正常访问。
2. 商品详情页是否支持直接访问。
3. 后端健康检查接口是否正常响应。
4. 商品列表接口及其数据库查询是否正常。
5. 指定商品的详情接口是否正常。
6. 指定商品的图片记录接口是否正常。
7. 指定的商品静态图片是否能够访问。
8. 未登录用户访问受保护接口时是否会被拒绝。
9. 使用错误密码登录时是否会被拒绝。
10. 使用正确账号和密码时是否能够登录。
11. 登录后获得的令牌是否能够读取当前用户信息。

## 基本用法

在项目根目录运行：

```bash
python tests/test.py
```

未指定参数时，脚本默认测试本机地址 `http://127.0.0.1`。如果网站位于其他主机或使用了域名，可以通过 `--base-url` 指定地址：

```bash
python tests/test.py --base-url "https://your-domain.example"
```

需要指定测试账号、商品和图片时，可以运行：

```bash
python tests/test.py \
  --base-url "https://your-domain.example" \
  --account "测试账号" \
  --password "测试密码" \
  --goods-id 1 \
  --image-path "/uploads/1/example.jpg"
```

`--image-path` 应填写网站中的 URL 路径，而不是服务器上的文件系统路径。

## 命令行参数

| 参数             | 作用                               | 默认值                            |
| ---------------- | ---------------------------------- | --------------------------------- |
| `--base-url`   | 待测试网站的根地址                 | `http://127.0.0.1`              |
| `--account`    | 用于登录测试的账号                 | `admin`                         |
| `--password`   | 用于登录测试的密码                 | `pass123`                       |
| `--goods-id`   | 用于详情查询的商品 ID              | `1`                             |
| `--image-path` | 用于访问测试的商品图片 URL 路径    | `/uploads/1/iphone15_front.jpg` |
| `--timeout`    | 每个 HTTP 请求的超时时间，单位为秒 | `20`                            |

可以通过以下命令查看脚本支持的全部参数：

```bash
python tests/test.py --help
```

## 使用环境变量

除了命令行参数，也可以使用环境变量提供测试配置：

| 环境变量            | 对应的命令行参数 |
| ------------------- | ---------------- |
| `BASE_URL`        | `--base-url`   |
| `TEST_ACCOUNT`    | `--account`    |
| `TEST_PASSWORD`   | `--password`   |
| `TEST_GOODS_ID`   | `--goods-id`   |
| `TEST_IMAGE_PATH` | `--image-path` |
| `TEST_TIMEOUT`    | `--timeout`    |

Linux 环境下的使用示例：

```bash
export BASE_URL="https://your-domain.example"
export TEST_ACCOUNT="测试账号"
export TEST_PASSWORD="测试密码"
export TEST_GOODS_ID="1"
export TEST_IMAGE_PATH="/uploads/1/example.jpg"

python tests/test.py
```

命令行参数的优先级高于对应的环境变量。建议通过环境变量传入实际密码，避免把真实账号密码写进代码或提交到 Git 仓库。

## 测试结果

每一项检查都会输出一行结果：

- `[PASS]` 表示该项测试通过。
- `[FAIL]` 表示该项测试失败，后面会显示 HTTP 状态码或响应内容摘要。

测试结束后会显示通过数、失败数和总测试数。所有项目通过时，程序退出码为 `0`；只要存在失败项目，退出码就是 `1`。因此，该脚本也可以在自动部署或持续集成流程中用于判断部署是否成功。

## 常见问题

### 网站无法连接

检查网站服务是否已经启动、目标地址是否正确，以及防火墙或云服务器安全组是否允许相应端口访问。

### 商品详情或图片测试失败

确认 `--goods-id` 对应的商品确实存在，并检查 `--image-path` 是否与该商品的实际图片 URL 一致。

### 正确账号登录仍然失败

确认测试账号和密码正确、账号状态正常，并检查后端登录接口是否已经启动。建议使用专门的测试账号，不要使用包含敏感数据的个人账号。

### 请求超时

可以适当增大超时时间，例如：

```bash
python tests/test.py --timeout 60
```
